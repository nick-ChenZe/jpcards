# 日札界面与动效规范

本文记录当前实现与验收标准。业务需求见 [requirements.md](requirements.md)，启动、配置和部署见
[development.md](development.md)。

## 品牌与纸色

品牌为「日札」，保留圆形日光卡片标志。`packages/frontend/src/assets/rizha-mark.svg` 为独立图标，`rizha-logo.svg`
为横版字标，另有单色和反白版本；均为透明底纯路径，不依赖设备字体。

暖和纸底、低饱和墨色、细线与朱印是主视觉。页头保留主 Logo。朱印狐暂时从界面移除，后续重新设计；加载和空态保留清楚的文字提示。日签墙日期页以横向图文列表展示，可在内容区滚动，打开单张时显示读取状态。可选朱印手帖、抹茶文库、墨色诗笺三种纸色，偏好仅保存在当前浏览器。底部导航使用已确认原型中的「◈
/ ▤ / 縁 / ⚙︎」符号，选中时随纸色变墨，设置图标保留足够的视觉尺寸。

补充样式集中在 `packages/frontend/src/styles/hiyori.css`；纸色和登录过渡在
`lib/paperTheme.ts`、`lib/paperNavigation.ts`。

## 页面与高度分配

纸页高度跟随可见窗口
`100dvh`，桌面居中、手机铺满。标题、内容、底部导航分成三行，外层不滚动，不允许内容穿过导航。内容区不显示滚动条。

- 今日空白、等待和生成成功三态都使用纸页剩余高度。完成卡片、播放和「再抽一张」同屏可见，不使用第二个 viewport
  高度，也不按自然内容高度把按钮推出屏幕。
- 生成成功后先压缩插画、重复装饰和留白；日语正文、假名、中文译文与操作不能截断。插画画幅使用弹性高度，阅读字号随卡片可用高度适度调整，触控目标至少
  44px。
- 设置页在短屏收紧标志、留白与纸色选项，保留退出和管理入口。
- 今日不展示月历。日签墙以月历为主元素，点日期进入每天三张的分页，再进入详情；返回保留月份、日期和页码。
- 日签墙外层不滚动；历史长详情保留无滚动条的触摸阅读，不把整张日签压成不可读的小字。

## 登录与抽签

登录调用真实 Better Auth；失败保留表单和错误，成功刷新会话后翻页至目标路由。优先使用 View Transition，约 1.3
秒；不支持时使用不含输入值的临时纸页副本。减少动态效果偏好下跳过动画。

抽签中的按钮使用手绘 SVG 中心线，按照「抽 / 签 /
中」笔顺逐笔写出，书写结束短暂停留后循环；保持无障碍名称「抽签中」，不能让读屏器每笔重复播报。减少动态效果偏好下直接显示完整笔画。箭头使用
SVG，避免系统 emoji 渲染差异。

等待内容显示实际 `sentence / illustration / finishing` 阶段、已等待秒数和标注为预估的剩余时间，通常以此前成功耗时或 50
秒估算。不编造模型内部百分比；超过预估时明确仍在等待。语音与插画并行请求。

正式生图使用
`qwen-image-3.0`、1024×1024，`prompt_extend:false`。手绘和纸、水彩晕边、米白与低饱和色，底部三分之一留白，不生成文字。图片加载后以
2.4 秒渐扩软遮罩展开；减少动态效果下直接显示。

## 阅读与余签

日签仅显示一份正文。分词与原句完全一致时，以词级假名注音和细线区分词段，短助动词尾随前词换行。音频使用同一个实例，播放时当前词变为朱砂色；不叠加整句假名与罗马音。旧卡分词无法对齐时保留原始完整正文。

中文释义直接显示，以小「訳」印记作引导，不再设置「揭晓中文」。日期旁的小印记显示「余签 x
枚」，用尽时写「0」，不补成「00」；读取中写「—」。完整额度由无障碍描述提供，按钮下不再重复限额行。用尽后的停止按钮保持通栏，锁文案完整换行。

## 回归检查

修改布局后在 320×640、390×844、440×680，以及桌面 807×830 检查：

1. 今日空白、等待、成功（有图和无图）、长句，以及设置页。
2. 外层宽高无溢出，日签正文及译文完整，播放和再抽按钮不需要滑动即可到达，导航位于纸页内。
3. 抽签按钮实际逐笔绘制；减少动态效果时文字完整静止。
4. 日签墙、日期分页和返回仍可用，历史长详情的触摸阅读不受今日布局影响。

构建及检查命令见 AGENTS.md。完整前端 TypeScript 检查目前有旧的未使用 AI
组件依赖缺失，核验当前入口时要区分此类既有问题；不要为本页样式改动无关地重写这些组件。

# 日札 UI

将评审过的和纸原型接入现有 React 页面：登录、注册、今日抽签、日签墙、好友占位和个人设置。

品牌名为「日札」，采用选定的圆形日光卡片标志。`src/assets/rizha-mark.svg` 为独立图标， `rizha-logo.svg`
为含「日札」字标的横版，另附单色与反白版。SVG 均为透明底纯路径，字标不依赖设备字体。

- 暖和纸底、细线日轮、竖排纸签与朱印。页面在桌面居中，在手机上铺满宽度。
- 「我的日札」可选择朱印手帖、抹茶文库、墨色诗笺。偏好保存在当前浏览器；存储不可用时仍可切换。
- 登录仍调用 Better Auth，失败时保留表单及错误提示。成功后刷新会话，再通过 View Transition 将登录纸页翻开至原目标路由。
  播放约 1.3 秒的动画；不支持 View Transition
  时使用临时纸页层完成同样的翻页，临时副本不包含输入值。系统偏好减少动态效果时跳过翻页。
- 抽签等待时纸签轻摇；收到真实结果后展开卡片、落下朱印。生成按钮、服务器配额、失败提示、配图和语音回退沿用现有逻辑。
- 日语句子、读音、逐词播放高亮保留，中文释义改为点击揭晓。学习历史、日期筛选、热力图和管理员入口继续使用原有接口及权限。
- 好友仍为筹备状态。此版没有加入演示登录、模拟生成或外部图像依赖。

视觉补充在 `packages/frontend/src/styles/hiyori.css`，纸色偏好和登录过渡分别在
`lib/paperTheme.ts`、`lib/paperNavigation.ts`。

开发与部署沿用根目录 README。锁文件为 pnpm 8 格式，安装使用 `npx pnpm@8.15.9 install --frozen-lockfile`。

## 滚动与月历回归

应用使用固定于窗口的纸页布局：标题、内容、底部导航各占一行，只有中间内容滚动。足迹改为七列月历，支持按月查看、今天/已选日期标记和真实墨迹计数，不创建内部滚动区域。

在已登录的日签墙页面运行 `packages/frontend/tests/check-paper-layout.js`，应返回
`pass: true`。滚到内容底部后再运行一次，外层高度与窗口应相等，导航须位于纸页边界内，月历不得出现横向或纵向溢出。原问题可复现为外层多出
20px 滚动、导航越界及热力图 1px 纵向溢出。

底部导航恢复原型中的「◈ / ▤ / 縁 / ⚙︎」纸签符号和细字标签，选中时随当前纸色变墨，不使用通用网页导航图标。

今日页只呈现抽签与日签内容；月历足迹集中放在日签墙，不在首页重复展示。

## 生图与日签墙（2026-10-26）

- 正式模型仍是 qwen-image-3.0，1024×1024，关闭
  prompt_extend；手绘和纸、水彩晕边、米白与低饱和色，画面下三分之一留白，不生成文字。
- 语音与插画并行。POST /api/card 可接受 application/x-ndjson，回传真实 sentence / illustration / finishing
  阶段和最终状态；普通 JSON 调用保持原行为。
- 等待页显示预估剩余时间、已等待时间和三个阶段；无模型内部百分比。超时预估会明确提示仍在等待，成功耗时供本机后续预估使用。
- 已加载图片用 2.4 秒渐扩软遮罩展开，减少动态效果偏好下直接显示。抽签箭头使用 SVG。
- 日签墙只展示月历，点日期进入每天三张的分页，再点单张进入详情。返回保留日期和页码。外层不滚动，长详情保留可滚动阅读但隐藏滚动条。

## 阅读排版与余签（2026-10-26）

日签只展示一份正文。分词与原句一致时，用词级假名注音和细线区分词段，跟随同一份音频以朱砂色标注当前词；不再叠加整句假名、整句罗马音。旧卡分词对不齐时保留完整原句。中文释义默认显示，余签数移到日期旁的小印记，按钮下不再显示额度行。

## 页面滚动（2026-10-26）

内容区统一隐藏滚动条，保留触摸、滚轮和键盘滚动。今日初始页和等待页适配纸张内的可用高度；生成结果按自然内容高度排版，取消旧的整屏高度约束。设置页的标志、留白和纸色选项在短屏收紧，主要按钮保留
44px 点击高度。已检查 320×640、390×844 和 440×680：初始页、设置页无需滚动，长日签可滚到末尾且无外层溢出。

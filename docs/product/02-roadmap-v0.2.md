# Roadmap (v0.2)

## Phase 1: Requirement Lock (Completed)

- Lock product direction to AI coach + flashcards
- Lock core audience and value proposition
- Confirm MVP exclusions (no custom cards, no JLPT onboarding)

## Phase 2: MVP Core Build

- Milestone M1: mobile-first flashcard flow + spaced repetition
- Milestone M2: AI explanation integration and quality guardrails
- Milestone M2.1: client-side BYO Provider settings (provider/key/model/endpoint)
- Milestone M3: progress dashboard and session summaries

## Phase 3: Launch-Ready Productization

- Add one-time purchase flow and entitlement checks
- Add provider setup guidance and recovery UX for configuration errors
- Improve UX polish for daily-use speed
- Add robust error and empty states
- Complete end-to-end smoke tests

## Phase 4: Launch and Learn

- Release H5-first product to public users
- Observe learning and conversion metrics
- Prioritize improvements based on usage data

## MVP Exit Criteria

- Core loop (study -> review -> progress) works end-to-end on mobile
- AI explanation is stable and readable in production
- Client-side provider configuration works with selected V1 providers
- One-time payment flow is functional and testable
- Critical launch metrics are instrumented
- No P0/P1 issues in main paths

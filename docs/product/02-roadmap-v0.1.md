# Roadmap (v0.1 Draft)

## Phase 1: Discovery and Requirement Lock

- Confirm target users and positioning
- Confirm MVP scope and non-goals
- Define metric targets for first release

## Phase 2: MVP Build

- Milestone M1: learning flow and review engine
- Milestone M2: progress tracking and daily plan
- Milestone M3: lightweight AI assist

## Phase 3: MVP Polish and Launch Readiness

- Improve UX details and edge-case handling
- Add onboarding guidance and empty states
- Run internal test and data sanity checks

## Phase 4: Post-Launch Iteration

- Improve retention loops based on user behavior
- Evaluate custom content and JLPT-path expansion

## Release Exit Criteria (MVP)

- Core learning loop works end-to-end
- Data persistence is stable
- Baseline metrics are instrumented
- No critical bugs in main flows
